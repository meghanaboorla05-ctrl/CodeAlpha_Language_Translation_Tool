# 🌐 Language Translation Tool

## 📌 Project Description

The Language Translation Tool is a web-based application developed using Python and Flask. It allows users to enter text, select a source language and target language, and translate the text using a translation service.

This project was developed as part of the CodeAlpha Artificial Intelligence Internship.

## ✨ Features

- Enter text for translation
- Select source language
- Select target language
- Translate text using a translation API
- Display translated text
- Copy translated text using the Copy Translation button
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Requests
- Translation API
